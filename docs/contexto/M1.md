## 2. Componentes do Núcleo Implementados

1. **Esquemas Pydantic (`src/docforja/esquemas/`):**
   * `Plano`, `Bloco`, `Shot`, `Ativo`, `Segmento`, `Candidato`, `Credito`, `Timeline`.
   * Enums de tipo de projeto (`longo`, `short_derivado`, `short_avulso`, `musica`), origens de ativos (`biblioteca`, `pesquisar`, `gerar`, `pedir_ao_usuario`, `dados`) e batidas dramáticas.
2. **Árvore de Pastas de Projetos (`src/docforja/nucleo/projeto.py`):**
   * Criação automatizada de todas as subpastas oficiais (`07 §4`):
     * `00_entrada/` (`roteiro.md`, `opcoes.yaml`, `glossario.yaml`, `documentos/`)
     * `01_plano/` (`plano.json`, `plano.md`, `pesquisa/`, etc.)
     * `02_midias/` (`biblioteca/`, `pesquisadas/`, `geradas/`, `manual/`, `nao_atribuidas/`, `tratadas/`, `escolhas.json`)
     * `03_audio/` (`<idioma>/`, `trilha/`, `sfx/`)
     * `04_montagem/` (`<idioma>/blocos/`)
     * `05_saida/` (`<idioma>/`, `elementos/`)
     * `sistema/` (`banco.db`, `eventos.jsonl`, `logs/`, `cache/`)
3. **Banco de Dados SQLite (`src/docforja/nucleo/banco.py`):**
   * Persistência em `<projeto>/sistema/banco.db`.
   * Tabelas `etapas`, `subetapas` e `meta`.
   * Suporte a status, medição de duração, idempotência via hash de entrada e invalidação em cascata.
4. **Semáforo de GPU com Agrupamento por Modelo (`src/docforja/nucleo/gpu.py`):**
   * Controle de concorrência e acesso exclusivo à RTX 3060 (12 GB).
   * Agrupamento inteligente: tarefas sucessivas que utilizam o mesmo modelo reaproveitam a VRAM; ao alternar modelos, descarrega o anterior antes de liberar o lock.
5. **Cotas de Provedor e Fallback (`src/docforja/nucleo/cotas.py`):**
   * Rastreamento de requisições e tokens.
   * Fallback transparente para o Ollama local (`qwen3:8b`) em caso de esgotamento de cota ou indisponibilidade do 9Router.
6. **Roteador LLM e Reparo de JSON (`src/docforja/llm/`):**
   * `roteador.py`: Integração com LiteLLM / 9Router (endpoint OpenAI-compatível em `http://127.0.0.1:20128/v1`) com fallback para Ollama.
   * `reparo.py`: Extração e sanitização leniente de JSON com tentativa de reparo guiado via Ollama local quando o JSON vier corrompido.
7. **DAG e Executor de Pipeline (`src/docforja/nucleo/etapas.py` e `executor.py`):**
   * Leitura de `config/pipeline.yaml` para todos os 4 tipos de produções.
   * Execução paralela de etapas independentes.
   * Retomada segura após cancelamento/kill do processo (`executando` -> `pendente`).
   * Gate `REVISAO` com pausa explícita e retomada sob aprovação.
   * Invalidação seletiva: redefinir um ativo ou etapa invalida apenas as etapas dependentes a jusante.

## 3. Interface Web e API FastAPI

1. **Servidor API (`src/docforja/api.py`):**
   * `GET /api/saude`: Status da GPU, serviços e cotas.
   * `GET /api/projetos` e `POST /api/projetos`: Criação e listagem de projetos.
   * `GET /api/projetos/{slug}`: Detalhes, opções e etapas do projeto.
   * `POST /api/projetos/{slug}/executar` e `POST /api/projetos/{slug}/aprovar_gate`.
   * `GET /api/eventos`: Fluxo de eventos em tempo real via Server-Sent Events (SSE).
   * Servir o build estático de `src/docforja/web_dist/` com fallback para SPA em `http://127.0.0.1:7860`.
2. **Frontend React (`web/`):**
   * Desenvolvido com React 18, Vite e Tailwind CSS seguindo fielmente os tokens de `docs/construtor/14-interface-ui.md §3` e o protótipo `mockups/docforja-ui.html`.
   * Sidebar completa e barra superior com pílulas de GPU e cota em tempo real.
   * Paleta de comandos global (`Ctrl+K` com `cmdk`).
   * **Tela Início (14 §5.1):** Cartão de projeto ativo ("Continuar de onde parou"), cartões de criação rápida, saúde do sistema e lista de projetos.
   * **Tela Criar (14 §5.2):** Wizard em 4 passos com contador de palavras e estimativa de duração ao vivo (~145 palavras/min).
   * Build compilado com sucesso (`src/docforja/web_dist/index.html` e assets).
3. **Comandos CLI (`src/docforja/cli.py`):**
   * `docforja novo <nome> [--tipo] [--roteiro]`: Cria projeto com estrutura completa.
   * `docforja status [slug]`: Exibe tabelas Rich com GPU, cotas e status de etapas.
   * `docforja executar <slug> [--aprovar-gate]`: Executa o pipeline.
   * `docforja ui [--port] [--host]`: Inicia o servidor local e abre o navegador.
